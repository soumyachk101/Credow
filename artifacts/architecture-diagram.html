1 Credit Allocation Lifecycle

Company Owner creates company
→
Onboarding wizard (5 steps)
→
Manager creates allocation
→
DB: INSERT allocation + transaction
→
Employee sees unclaimed_credits

Allocation status: active → suspended → terminated. Unclaimed credits roll back to company on termination.

2 x402 Payment Flow (Algorand Exact Scheme)

1. Employee clicks "Pay" in Claims page
2. Frontend claims credits from allocation (DB update)
3. Build USDC ASA transfer (ASA 31,566,704)
4. Wallet (Pera/Lute) signs via transactionSigner
5. Submit signed tx to Algorand, wait for confirmation
6. Update payment_record: pending → confirmed

Nonce = allocation_id:service_id:timestamp for idempotency. Faucet available for testnet USDC.

3 Yield Generation & Distribution

Unclaimed credits eligible (> $50, > 7 days)
→
calculateYield() — simple interest
→
70% company_share · 30% employee_share
→
distributeYield() — credit employee balance
→
Immutable transaction record

APY capped at configurable basis points. Pause mechanism for emergencies. Simple interest (not compound) for legal safety.

7 Yield Vault Smart Contract

Method Type Access Purpose
create @abimethod Deploy (once) Initialize global state: admin, USDC asset ID, APY cap, share ratios, min balance
deposit @abimethod Admin only Deposit USDC into company position; updates BoxMap + total_deposits
claimYield @abimethod Any caller Calculate and return accrued yield for a company position; resets last_claim_round
withdraw @abimethod Admin only Withdraw principal from company position with balance validation
updateApy @abimethod Admin only Set new APY (capped at apy_cap_bps)
togglePause @abimethod Admin only Emergency pause — blocks deposit/claim/withdraw
getAvailableYield @abimethod (readonly) Any caller View: current accrued yield for a company
getCompanyBalance @abimethod (readonly) Any caller View: principal deposited for a company
getCompanyPosition @abimethod (readonly) Any caller View: full PositionData for a company

State storage: GlobalState for admin, USDC asset ID, totals, APY cap, pause flag. BoxMap for per-company positions (key: company_addr, value: PositionData with deposited, last_deposit_round, last_claim_round, active). Yield = principal × APY_bps × rounds_elapsed / (6,312,000 × 10,000); employee share calculated from basis points.

10 Key Architectural Decisions

DecisionRationale
Web2 core + Web3 edgeSupabase handles auth/CRUD; Algorand only for settlement and yield — best UX + efficiency
Budget allocation, not payrollCredits are not salaries — avoids tax/liability complexity
USDC over ALGOStable value, simpler accounting for corporate budgets
Simple interest yieldLegally cleaner than compound; easier to explain to users
70/30 yield splitCompany gets bulk yield; employees get incentive without being compensation
Zustand over ReduxLess boilerplate, simpler API for 4 stores
BoxMap for positionsO(1) per-company lookups on-chain; scales to many companies
Immutable transaction ledgerINSERT-only with rollback on failure — financial integrity
x402 exact schemeStandard HTTP 402 → on-chain payment; no custom protocol negotiation
Algorand over StellarBetter TypeScript support (Puya-TS), simpler smart contracts
